# AI Receptionist Script

Use this skill to design a practical receptionist script that captures, qualifies, books, and escalates leads.

## Inputs

Ask for:
- Business type.
- Channels: phone, SMS, WhatsApp, website chat, email.
- Lead types handled.
- Booking rules.
- Escalation rules.
- CRM fields.
- Brand voice.
- Compliance constraints.

## Script Structure

Build:
1. Greeting.
2. Consent and identity check when needed.
3. One-question-at-a-time qualification.
4. Booking or routing logic.
5. Human escalation.
6. CRM summary.
7. Opt-out / stop handling for messaging.

## Output Format

```markdown
# AI Receptionist Script

## Role

## Goals

## Opening

## Qualification Questions

## Booking Logic

## Escalation Rules

## CRM Summary Format

## Failure / Edge Cases
```

## Voice Rules

- Be concise.
- Ask one question at a time.
- Never pretend to be human.
- Never invent availability, pricing, property facts, or legal answers.
- Escalate urgent, angry, legal, pricing, contract, financing, or Fair Housing-sensitive questions.
